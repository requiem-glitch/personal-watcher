# Personal Watcher

Personal Watcher — сервис для автоматического мониторинга внешних веб-ресурсов.

Пользователь добавляет URL и задаёт условие проверки. Сервис периодически обращается к указанному ресурсу, анализирует ответ и сохраняет историю проверок. Это позволяет отслеживать состояние сайтов, API и отдельных страниц без необходимости проверять их вручную.

Personal Watcher может использоваться, например, чтобы определить, что:

- API endpoint перестал возвращать ожидаемый HTTP status;
- на странице появился нужный текст;
- содержимое страницы изменилось;
- товар снова появился в наличии;
- цена изменилась;
- вышел новый релиз;
- изменилось определённое значение в JSON-ответе.

## Как это работает

Для каждого наблюдаемого ресурса создаётся watcher. Он содержит URL, тип проверки, интервал между проверками и необходимые параметры условия.

Сервис по расписанию запускает проверки активных watchers, выполняет HTTP-запросы к внешним ресурсам и сохраняет результаты. Для каждой проверки можно хранить HTTP status, время ответа, результат сопоставления с условием, информацию об изменении содержимого и возникшие ошибки.

Поддерживаемые типы проверок:

- `status_code` — проверка ожидаемого HTTP status;
- `contains_text` — поиск заданного текста в ответе;
- `body_changed` — обнаружение изменения содержимого ресурса.

История проверок позволяет видеть состояние ресурса во времени и определять момент возникновения изменений или ошибок.

## Назначение

Personal Watcher подходит для мониторинга API, сайтов, страниц товаров, документации, релизов и других ресурсов, доступных по HTTP.

В дальнейшем сервис может поддерживать уведомления при выполнении заданного условия — например, при недоступности endpoint, появлении товара в наличии или изменении содержимого страницы.
